# Tirich Mir View Hotel — Full Demo Website (Sample)

Demo preview built by Muhammad Ihtisham as a free 1-page → full-site sample for outreach to Tirich Mir View Hotel, Chitral Town.

**This is NOT the live hotel website.** Prices, room types, and About text are drafts from public listings (603 Google reviews, ~$64/night, Jamia Masjid Rd, garden/terrace/restaurant). Real photos, room types, and prices go in after the hotel approves.

## Pages
- `index.html` — Home (hero, why book direct, rooms at a glance)
- `rooms.html` — Rooms & prices + amenities
- `gallery.html` — Gallery placeholders for real photos
- `about.html` — About + nearby (Kalash, Garam Chashma, Shandur)
- `contact.html` — Book / Contact + booking-inquiry form (opens WhatsApp with details)
- `style.css` — Shared styles, mobile-friendly

## How to view
Open `index.html` in a browser, or serve the folder:
```
python3 -m http.server 8000
```
Then open http://localhost:8000
